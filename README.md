# heart_decision_tree
# Task 5: Decision Trees & Random Forests

## Objective
Classify heart disease using tree-based models and evaluate model performance.

## Tools Used
- Python (Pandas, Scikit-learn, Graphviz, Seaborn, Matplotlib)

## Models
- Decision Tree
- Random Forest

## Evaluation
- Accuracy
- Cross-Validation
- Feature Importances
- Overfitting control (via max_depth)

## Dataset
[Heart Disease Dataset](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset)
